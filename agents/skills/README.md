# Vault Agent Skills

This folder contains reusable Agent Skills that guide work in this vault. Open [[agents/skills/INDEX|the Agent Skills index]] to find the applicable skill and open its `SKILL.md` before acting.

## Using Skills

1. Choose the smallest skill that matches the task.
2. Read its `SKILL.md` completely, including any referenced resources that apply.
3. Follow the skill’s workflow and preserve the vault’s existing links, embeds, metadata, and safety boundaries.

## Maintaining Skills

- Create or revise reusable vault skills with `skill-authoring`.
- Import or audit skills with `skill-ingestion`.
- Keep every direct child skill folder listed in [[agents/skills/INDEX|the Agent Skills index]].
- Add a skill only when its focused purpose and safety boundaries are clear.
