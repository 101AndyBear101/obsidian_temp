# Wiki Publishing Workflow

## Purpose

Provide a lightweight review sequence for turning source notes into a contextual wiki page.

## Publishing Workflow

1. Identify the audience and the question the page must answer.
2. Find or create the atomic notes that own the required facts and procedures.
3. Give reusable sections stable `##` headings.
4. Create a contextual overview and embed only the required headings.
5. Check every wikilink and embed target.
6. Confirm frontmatter relationships use plain lowercase-kebab-case filenames (e.g. `homelab`).
7. Review the page in Obsidian reading view and confirm its Base views include it.

## Validation

The workflow is complete when the contextual page reads coherently, every canonical section has one owner, and edits to a source heading appear automatically in the overview.
