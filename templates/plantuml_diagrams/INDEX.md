# PlantUML Diagram Templates

Use these templates with a `plantuml` fenced block. Choose the smallest diagram that explains the relationship or process you are documenting.

## Structure and Architecture

- [[class-diagram|Class diagram]] — Model types, fields, operations, and static relationships.
- [[object-diagram|Object diagram]] — Show concrete instances and their links at one point in time.
- [[component-diagram|Component diagram]] — Explain service boundaries and dependencies.
- [[deployment-diagram|Deployment diagram]] — Map software components onto hosts or runtime nodes.
- [[network-diagram-nwdiag|Network diagram (NWDiag)]] — Document network segments, addresses, and attached devices.
- [[archimate-diagram|ArchiMate diagram]] — Describe enterprise architecture layers and cross-layer relationships.

## Behavior and Interaction

- [[activity-diagram|Activity diagram]] — Map a workflow with actions, branches, and loops.
- [[sequence-diagram|Sequence diagram]] — Show messages exchanged over time.
- [[state-diagram|State diagram]] — Define allowed states and transitions.
- [[timing-diagram|Timing diagram]] — Compare state changes against time.
- [[use-case-diagram|Use-case diagram]] — Relate actors to system capabilities.
- [[sdl-diagram|SDL diagram]] — Model communicating processes and signals using SDL notation.

## Data, Planning, and Exploration

- [[entity-relationship-diagram|Entity relationship diagram]] — Define data entities, attributes, and cardinality.
- [[json-data-diagram|JSON data diagram]] — Present a JSON document’s nested structure.
- [[yaml-data-diagram|YAML data diagram]] — Present a YAML document’s nested structure.
- [[gantt-chart|Gantt chart]] — Schedule work, durations, and dependencies.
- [[work-breakdown-structure|Work breakdown structure]] — Break a project into hierarchical deliverables.
- [[mind-map|Mind map]] — Explore a topic as a hierarchy of ideas.

## Specialized Formats

- [[ditaa-diagram|Ditaa diagram]] — Draw lightweight ASCII-art diagrams; render as PNG.
- [[wireframe-salt-diagram|SALT wireframe]] — Sketch a simple user-interface layout.
- [[math-asciimath|AsciiMath]] — Render compact mathematical notation from AsciiMath.
- [[math-latex|LaTeX math]] — Render mathematical notation from LaTeX.
